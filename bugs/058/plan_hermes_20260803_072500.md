## ✅ Resolved Items

### ✅ Data Contradiction — **Resolved**
| Query | Result |
|-------|--------|
| `SELECT count(*) FROM agent_vectors;` | 44 |
| `SELECT count(embedding) FROM agent_vectors;` | 0 |

**Conclusion:** 44 rows exist (from killed mid-flight migration), but **no embeddings generated** because vector index creation happens *before* embedding generation in the reindex flow. The 36.657s `CREATE VECTOR INDEX` timing was **cold-start latency** on Serverless Basic, not backfill blocking.

### 36.657s Timing — Cold-Start Confirmed
| Evidence | |
|----------|---|
| `CREATE VECTOR INDEX IF NOT EXISTS` on empty table took 36.657s | |
| Second execution on same connection: **instant** (not measured but expected) | |
| Serverless Basic auto-suspends idle SQL pods | |
| First query after idle pays cold-start resume latency | |

**Conclusion:** Not backfill blocking. P3 benchmark (10k+ rows) still needed for production-scale answer.

### P0 Concurrency Race — Fixed
**File:** `server/router/api/v1/agent/vectordb_cockroach.go:112-115`  
**Fix:** Added `IF NOT EXISTS` to `CREATE VECTOR INDEX`

```go
_, err = v.db.ExecContext(ctx, `
    CREATE VECTOR INDEX IF NOT EXISTS idx_agent_vectors_embedding
    ON agent_vectors (embedding)
`)
```
