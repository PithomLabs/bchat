# Plan: Delete the RAG Search Explorer panel from Agent Admin (frontend only)

## Decision

User wants the panel **entirely removed from the UI** ("delete only the RAG Search Explorer
panel"). Backend stays intact — `HandleRAGSearch` (`server/router/api/v1/agent/handlers.go:5776`)
and its `adminGroup` route (`server/router/api/v1/v1.go:365`) are **not** touched, nor are
`HandleTestRAGSearch` / `HandleTenantRAGSearch` or the shared Go request/response structs.

The earlier "reversible flag-hide" plan was never implemented (source edits were blocked in
plan mode), so this is a clean deletion.

## What to remove

### 1. `web/src/pages/AgentAdmin.tsx`

- **Lines 110-113** — remove the `// RAG Search Explorer state` comment and the three
  panel-only `useState` declarations:
  ```ts
  const [showSearchExplorer, setShowSearchExplorer] = useState(false);
  const [searchQuery, setSearchQuery] = useState("");
  const [searchTopK, setSearchTopK] = useState(5);
  ```
  (Keep the Transcripts/Widget/Domain state that follows.)
- **Lines 156-157** — remove `ragSearchResults,` and `isSearchingRAG,` from the
  `agentAdminStore` destructure (they sit between `qaTestResults,` and `transcripts,`).
- **`handleRAGSearch`** function (starts ~line 353) — remove the whole function
  (panel-only; calls `agentAdminStore.searchRAG`).
- **Lines 1687-1845** — remove the entire panel block:
  `{/* RAG Search Explorer - Admin only */}` through its closing `)}` (the
  `{isAdmin && ( ... )}` wrapper). Leave the adjacent `Captured Leads` block (starts 1847)
  intact.

### 2. `web/src/store/v2/agentAdmin.ts`

These are exclusive to the panel, so remove them to avoid dead code:
- **Types** (around lines 225-246): the `RAGSearchResult` and `RAGSearchResponse`
  interfaces and the `// RAG Search Explorer types` comment. (Confirm nothing else imports
  them — they are only used by `searchRAG`/`clearRAGSearchResults`.)
- **State props** (around 485-487): `ragSearchResults` and `isSearchingRAG`.
- **Methods** (around 1039-1064): `searchRAG` and `clearRAGSearchResults`.
- **Exports** (around 1589-1591): remove `searchRAG` and `clearRAGSearchResults` from the
  returned store object.

### Notes / non-goals
- **Backend untouched** (per decision): `handlers.go` `HandleRAGSearch`, `v1.go` route
  `adminGroup.POST("/:slug/rag/search", ...)`, shared `RAGSearch*` Go structs, and the other
  two RAG-search handlers remain.
- **Locale strings** (`agent-admin.search-explorer-*`, `open-explorer`, `search-placeholder`,
  etc.) become unused — leave them (unused i18n keys are harmless and low-risk to leave).
- Removing the store props/methods is required so the `agentAdminStore` destructure
  (step 1, lines 156-157) still compiles; the component-level `useState` removals (step 1,
  lines 111-113) are required so there are no "declared but never read" TS errors.
