Setup & Testing Guide

Prerequisites

  • bchat backend running on port 8081
  • Agent Admin UI running on port 5230 (Station 5 only)
  • Demo tenants with KB content indexed (for Stations 1-3)

Quick Start

task run:rag

# Terminal 2 — Serve this demo page
cd widget/site && python -m http.server 8080

# Open in browser

Station Guide

  • Station 1 (Customer Support): Ask about water damage pricing, emergency response. Tests KB recall and policy adherence.
  • Station 2 (OM Stress Test): Long conversation testing memory. Give facts early, ask for them later. See bugs/om_stress_test.md for the full 10-test protocol.
  • Station 3 (RAG Self-Query): Ask bchat about its own architecture. Uses the 54MB indexed codebase docs as KB content.
  • Station 4 (Simulation): Click "Run Simulation" in the main header. Generates a multi-turn test conversation.
  • Station 5 (Admin): Loads the Agent Admin UI. Manage tenants, upload files, view RAG stats, trigger reindex.

Testing Tips

  • Use "Reset Session" button to start fresh (clears localStorage session ID)
  • Each station uses a separate iframe — no state leaks between stations
  • For OM testing, keep the same session open across multiple turns (don't reset)
  • Check bchat logs for observer/reflector triggers during OM tests
